<h2>📖 Sobre o Projeto</h2>

<p>
O <strong>Rock & Ride Festival Manager</strong> é um sistema em Python executado via terminal, criado para auxiliar na organização de eventos beneficentes envolvendo motociclismo e música rock.
O projeto aplica conceitos fundamentais de programação como funções, listas, dicionários, estruturas de repetição, condicionais e modularização.
</p>

<h2>🎯 Objetivo</h2>

<ul>
<li>Gerenciar categorias de motos participantes.</li>
<li>Controlar bandas e line-up do festival.</li>
<li>Automatizar operações de cadastro, consulta e remoção.</li>
<li>Disponibilizar informações do evento e FAQ.</li>
<li>Simular arrecadações beneficentes por meio de doações.</li>
</ul>

<h2>⚙️ Funcionalidades</h2>

✅ Visualizar Line-up do Festival<br>
✅ Consultar motos permitidas<br>
✅ Adicionar bandas<br>
✅ Remover bandas<br>
✅ Filtrar bandas por gênero musical<br>
✅ Sistema de doações simuladas<br>
✅ FAQ com dúvidas frequentes<br>
